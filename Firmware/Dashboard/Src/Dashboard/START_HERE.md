## 🎮 FIRST STEPS

### Test the Dashboard (No Hardware Needed)

1. Click **"Demo Mode"** button
2. Watch the dashboard come alive with simulated data!

### Connect to Real Device

#### Local Mode (Bluetooth/Serial)

1. Click **"Connect Device"**
2. Select your Bluetooth or Serial port
3. Start monitoring!

#### Remote Mode (IoT)

1. Click **"Local Mode"** to switch to **"Remote IoT"**
2. Click **"Connect Server"**
3. Enjoy remote monitoring!

## 🎯 KEY FEATURES TO TRY

### 1. WiFi Provisioning
- Go to **Controls** tab
- Enter WiFi SSID and Password
- Click **"Save to Device via Bluetooth"**
- Credentials saved to device EEPROM!

### 2. Calibration
- Adjust **Voltage Factor**
- Adjust **Current Factor**
- Click **"Apply Calibration"**

### 3. Relay Control
- Toggle **Master Switch** ON/OFF
- Enable/Disable **Auto-Reset Protection**

### 4. View Logs
- Go to **Logs** tab
- See all system events with timestamps
- Clear logs with one click

## 🔧 CUSTOMIZATION

### Change Server Port

```bash
PORT=8080 npm start
```

### Bind to Specific IP

```bash
HOST=192.168.1.100 npm start
```

### Use Environment File

1. Copy `.env.example` to `.env`
2. Edit values as needed
3. Start normally

## 🐛 COMMON ISSUES

### Server won't start
```bash
rm -rf node_modules
npm install
npm start
```

### Port already in use
```bash
PORT=8080 npm start
```

### Can't connect to device
- Try Demo Mode first
- Check Bluetooth pairing
- Use Chrome/Edge browser
