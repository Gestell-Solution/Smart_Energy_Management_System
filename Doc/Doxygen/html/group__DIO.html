Reads the state of a specific DIO pin.


This function retrieves the digital value (HIGH or LOW) of a given pin within a specified DIO port. The read value is stored in the variable pointed to by the InputValue pointer.
It accesses the corresponding PIN register to get the actual logic level present at the pin (useful for input pins).

Parameters
GroupNameThe name of the Port group (PORTA, PORTB, PORTC,PORTD).
PinNumberThe pin number within the specified port (PIN0—>PIN7).
InputValuePointer to a variable where the reading level will be stored: == 0: LOW
== 1: HIGH
