PM_Init ( void  )

Initialize all of the needed Modules in this Driver.

Initialize all of the needed Modules in this Driver.

Sets up necessary peripherals:

  • External Interrupts (EXTI) for reset button.
  • Timer1 (if used for timing protection).
  • Output actuators: Buzzer, Relays, RGB LED.
  • Input sensors: Voltage, Current.
  • Display Manager (for showing status). Configures the system to start in the Safe (Green) state.

Warning
Please Make Sure not to press the button till the problem is fixed

Resets the Normal operation after fixing the problem.

Called via External Interrupt (Button Press). If the system considers the fault condition "Fixed" (state logic), this restores normal operation:

  • Closes Relays (Power ON).
  • Turns off Buzzer.
  • Sets RGB LED to GREEN.

◆ PM_Update()

PM_Update ( void  )

Checks Periodically all the Protection Conditions.

Checks Periodically all the Protection Conditions.

This function should be called in the main loop.

  1. Updates measurement readings.
  2. Compares readings with Vrms_Threshold, Irms_Threshold, and P_Threshold.
  3. If limits exceeded:
    • Sets state to Danger.
    • Opens all Relays (CUTOFF).
    • Turns RGB LED to RED.
    • Activates Buzzer.
    • Logs fault values to g_SystemData.
  4. Handles UI updates for Safe/Danger states.
    Returns
    void
