Detailed Description

This file contains configuration settings for Timer0 specifications.

This header file defines several macros that allow for defining Conifgurations based on project requirements. It includes configuration settings for Timer0 Settings.

◆ CompareMatchValue

#define CompareMatchValue   ((T0_MilliSecond / ((T0_ClkTime) * T0_NUMBER_OF_CTC)) ) -1

Calculates the OCR0 value for Timer0 in CTC mode.

Determines the value to load into OCR0 to achieve the desired tick resolution.

Note
Depends on clock frequency, prescaler, and desired time resolution.
Warning
Ensure that the result fits within 8-bit range (0–255).

◆ IsCOM_FlagSet

#define IsCOM_FlagSet   GetBit(TIFR_Reg, OCF0_Bit)

Checks if the Timer0 Compare Match flag is set.

Reads the OCF0 bit from the TIFR register to determine if a compare match occurred.

Returns
Boolean value: 1 if set, 0 if not.
Note
Used in polling-based delay or status checking.

◆ T0_ScheduledTasksNum

#define T0_ScheduledTasksNum   3

Defines the maximum number of concurrent scheduled tasks for Timer0.

Limits the number of non-blocking delays that can be managed simultaneously.

Note

Warning
must be careful with ram possible tasks.

◆ Timer0_CompareOutputMode

#define Timer0_CompareOutputMode   T0_NormalPort

Sets the compare output behavior for Timer0.

In Normal Port mode, the OC0 pin is disconnected and used as a regular I/O.

Used when no PWM or toggling output is needed.
