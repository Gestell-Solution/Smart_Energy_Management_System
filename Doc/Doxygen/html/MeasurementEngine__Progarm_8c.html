Detailed Description

Implementation of the Measurement Engine Module.

This module is responsible for acquiring raw sensor data (Voltage and Current), performing RMS calculations, and deriving Power and Energy values. It acts as the central hub for all electrical measurements in the system.

All hardware-specific interactions are abstracted via HAL functions.
