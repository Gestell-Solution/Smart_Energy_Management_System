Detailed Description

Configuration settings for Timer1 specifications.

This header file defines macros and constants for configuring Timer1 based on project requirements, including prescaler, waveform mode, compare output behavior, and interrupt settings.

◆ Timer1_Sampling_Clks

#define Timer1_Sampling_Clks   1250

Defines the Number of clock Ticks for Timer1 Compare Match A and B.

This macro sets the value to be loaded into the OCR1A and OCR1B registers, which determines the compare match value for Timer1 in CTC mode , which is used to trigger ADC sampling.

Note
The actual timing depends on the system clock frequency and the selected prescaler.
This Value with prescaler 64 and F_CPU 8MHz will result in 10ms time interval.

◆ Timer1_TOPvalue

#define Timer1_TOPvalue   1250

Defines the TOP value for Timer1 in CTC mode using ICR1.

This macro sets the value to be loaded into the ICR1 register, which determines the maximum count value (TOP) for Timer1 in CTC mode. The timer resets when it reaches this value, creating a periodic interval.

Note
The actual timing depends on the system clock frequency and the selected prescaler.
Warning
Ensure that the value fits within the 16-bit range (0–65535) to avoid overflow.
