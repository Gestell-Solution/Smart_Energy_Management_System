Detailed Description

This File is for declaring main APIs And needed Macros for the App layer Communication Manager.

  • This Module is about Decoding incoming commands and route them to the appropriate module.
    • Provide a unified interface for communication with both Bluetooth (local) and Wi-Fi (remote) and Applying the wanted framing Protocol and lastly maintain the synchronization between UART and Network Layer.
