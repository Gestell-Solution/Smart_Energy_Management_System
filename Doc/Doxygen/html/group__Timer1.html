mTIMER1_Init ( void  )

Initializes Timer1 in CTC (Clear Timer on Compare Match) mode.

This function configures Timer1 registers with predefined settings for CTC mode. It sets the waveform generation mode, compare match behavior, and prescaler options.

Returns
void
Note
This function must be called before starting the timer or registering a callback.
