Detailed Description

Implementation of the Relay Control Driver.

This module handles the low-level activation and deactivation of relays. It maps abstract relay IDs (e.g., hRELAY_0) to specific physical ports and pins. It abstracts the active-high/active-low logic defined in the configuration.
