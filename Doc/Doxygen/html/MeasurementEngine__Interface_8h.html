Detailed Description

Interface file for the Measurement Engine module.

This file provides the function prototypes for initializing, updating, and retrieving electrical measurement values such as RMS voltage, RMS current, power, and total energy consumption. The Measurement Engine interacts with current and voltage sensor drivers to compute real-time and accumulated electrical parameters.
