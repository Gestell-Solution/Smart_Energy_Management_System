Detailed Description

Implementation of Buzzer control driver (On, Off, Beep, Alert, and Periodic modes).

This module controls the buzzer connected to the MCU. It provides multiple operating modes: ON, OFF, single beep, periodic beep, and alert beep. The buzzer timing is handled using Timer0 delay callbacks.
