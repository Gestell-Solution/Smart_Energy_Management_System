Detailed Description

LCD HAL implementation.

Implements the LCD driver: initialization sequence, low-level command/data transfer routines, high-level helpers (print, clear, set cursor), timing delays and any required synchronization. This source uses configuration from LCD_Config.h and private definitions from LCD_Private.h.

◆ LinesOfDisplay

LinesOfDisplay = Rows_Addresses_Array
static

Holds the starting DDRAM addresses for each LCD row.

This static array is initialized using the predefined macro Rows_Addresses_Array in the configuration file, which contains the start addresses for Row 1 to Row 4. It is used to calculate the cursor position on the LCD when setting the DDRAM address.
