Detailed Description

Program file for the HC-05 Bluetooth driver.

This file contains the implementation of all APIs used for initializing and communicating with the HC-05 Bluetooth module via UART0. It includes functions to send and receive data, either as single bytes, strings, or buffers. The HC-05 driver provides a high-level interface for Bluetooth serial communication.
