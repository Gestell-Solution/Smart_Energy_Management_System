Detailed Description

This section defines the prescaler values for the ADC module.

This section defines masks for selecting ADC channels.

This section defines the operation modes for the ADC module.

This section defines the enable/disable options for the ADC module. by setting or clearing the ADEN bit in the ADCSRA register.

This section defines the enable/disable options for the ADC interrupt feature.

This section defines the enable/disable options for the ADC auto trigger feature.

This section defines the auto trigger source options for the ADC module.

This section defines the voltage reference options for the ADC module.

This section defines the channel selection options for the ADC module.

The prescaler values determine the division factor for the ADC clock.

Enabling auto trigger allows the ADC to start conversions automatically based on the selected trigger source.

Note
This feature is useful for applications that require periodic or event-driven ADC conversions without CPU intervention.
