hLCD_Init ( void  )

Initialize the LCD in the configured interface mode (e.g. 4-bit).

Performs the required power-up and initialization sequence for the LCD controller (function set, display on/off, clear display, entry mode set). Should be called once before any other LCD API.

Returns
void
Note
Timing delays required by the LCD controller are handled inside this function. Do not call other LCD functions until initialization completes.
