◆ mADC_Init()

void mADC_Init ( )

Initializes the ADC peripheral.


  • Configures ADMUX: Reference Voltage, Adjustment.
  • Configures ADCSRA: Prescaler, Auto-Trigger Enable, Interrupt Enable.
  • Configures SFIOR: Trigger Source (if Auto-Trigger enabled).
  • Enables the ADC hardware.
    Returns
    void

Configuration Map:

  1. ADMUX (Ref + LeftAdjust + Channel)
  2. ADCSRA (Enable + Start + AutoTrig + IntFlag + IntEnable + Prescaler)
  3. SFIOR (Special Function IO, for Trigger Source)

uint16_t mADC_Read ( uint8_t  channel)

This Function reads the ADC value from the specified channel.

Returns
returns the 10-bit ADC value.
Parameters
channel: the ADC channel number (0-7) in our project (0-1).
Warning
to use this function the ADC must be initialized in Synchronous_Mode from the config.h

This Function reads the ADC value from the specified channel.

  1. Selects the channel in ADMUX.

    1. Starts Conversion (ADSC).
    2. Busy-waits until ADSC clears (or ADIF sets).
    3. Returns the 10-bit result.

    Note: Disabling interrupts is recommended during this call if mixed mode is used, though this implementation manually clears the flag.

    Parameters
    [in]channelChannel Number (0-7).
    Returns
    uint16_t 10-bit ADC result.
