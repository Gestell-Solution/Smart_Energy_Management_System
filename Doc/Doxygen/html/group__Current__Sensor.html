void hCurrent_Calibrate ( void  )

Calibrates the zero-current offset of the ACS712 sensor.

Averages multiple ADC readings while no current is flowing to determine the baseline voltage offset.

Warning
Ensure no current is flowing through the sensor during calibration.
Note
This function should be called once during setup or when environmental conditions change.
