Detailed Description

APIs for electrical measurement processing.

The Measurement Engine is responsible for acquiring, processing, and calculating key electrical parameters including RMS voltage/current, active power, and energy consumption.

◆ ME_Update()

void ME_Update ( void  )

Periodically updates measurement calculations.

This function should be called at a fixed sampling rate to process new ADC samples for voltage and current, updating the RMS, power, and energy calculations.

Warning
Must be called periodically (e.g., via timer interrupt or scheduler).

Periodically updates measurement calculations.

Triggers a read operation from the sensors to get the latest RMS values. Calculates:

  • Power = Vrms * Irms (assuming Unity Power Factor for simplicity, or sensor provides real power).
  • Energy = Energy + (Power * Sample_Interval). This function should be called periodically at a fixed interval (ME_SAMPLE_INTERVAL).
