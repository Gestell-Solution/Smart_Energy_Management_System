Disable the selected external interrupt.

This function clears the corresponding enable bit (INT0, INT1, or INT2) in the GICR register to prevent the interrupt request from occurring.

void mEXTI_Init ( uint8_t  source,
uint8_t  senseControl 
)

Initialize the external interrupt configuration.

This function configures the selected external interrupt (EXTI0, EXTI1, or EXTI2) with the desired sense control (LOW LEVEL, ANY CHANGE, FALLING EDGE, RISING EDGE). It sets the corresponding bits in MCUCR or MCUCSR registers.

Parameters
sourceSpecifies which EXTI line to configure (EXTI0, EXTI1, EXTI2).
senseControlSpecifies the interrupt triggering condition. Possible values: EXT_LOW_LEVEL, EXT_AnyCHANGE, EXT_FALLING_EDGE, EXT_RISING_EDGE.

)

Set the callback function for a specific external interrupt source.

This function links a user-defined function (callback) to a specific EXTI line. When the interrupt occurs, the linked callback function will be executed automatically.

Parameters
sourceSpecifies which EXTI line to attach the callback (EXTI0, EXTI1, EXTI2).
PFPointer to the function to be executed when the interrupt occurs.
Warning
The callback pointer must not be NULL.
