\doxysubsubsection{Detailed Description}
This section contains configuration settings for enabling or disabling various MCAL modules. 

The Macros defined in this section allow for easy enabling or disabling of specific MCAL modules based on project requirements \begin{DoxyNote}{Note}
The available options for each module are \textquotesingle{}Enable\textquotesingle{} and \textquotesingle{}Disable\textquotesingle{}. 
\end{DoxyNote}
