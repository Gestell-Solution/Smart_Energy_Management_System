 The serialport stream interface. This package requires bindings to work.

You\textquotesingle{}d use this if you want to keep your package size down by requiring only the parts of serialport that you want to use. It is used internally in the {\ttfamily serialport} package.

This is how you use it.


\begin{DoxyCode}{0}
\DoxyCodeLine{const\ \{\ SerialPortStream\ \}\ =\ require('@serialport/stream')}
\DoxyCodeLine{const\ \{\ autoDetect\ \}\ =\ require('@serialport/bindings-\/cpp')}
\DoxyCodeLine{const\ binding\ =\ autoDetect()}
\DoxyCodeLine{const\ port\ =\ new\ SerialPortStream(\{\ binding,\ path:\ '/dev/ttyay',\ baudRate:\ 9600\ \})}

\end{DoxyCode}
