\doxysubsection{Detailed Description}
A Java\+Script value of unknown type.

For type-\/specific operations, convert to one of the \doxylink{classNapi_1_1Value}{Value} subclasses using a {\ttfamily To\texorpdfstring{$\ast$}{*}} or {\ttfamily \doxylink{classNapi_1_1Value_a9c1a9c4eca9617b0aafbe311c946982a}{As()}} method. The {\ttfamily To\texorpdfstring{$\ast$}{*}} methods do type coercion; the {\ttfamily \doxylink{classNapi_1_1Value_a9c1a9c4eca9617b0aafbe311c946982a}{As()}} method does not. \begin{DoxyVerb}Napi::Value value = ...
if (!value.IsString()) throw Napi::TypeError::New(env, "Invalid
arg..."); Napi::String str = value.As<Napi::String>(); // Cast to a
string value
