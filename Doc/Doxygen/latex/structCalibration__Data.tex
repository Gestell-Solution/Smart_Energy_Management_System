\doxysubsection{Detailed Description}
Holds running data used to compute the ADC zero offset (calibration). 

Used when calibrating the ACS712 sensor to determine the baseline ADC value when no current is flowing. The driver accumulates ADC readings and computes an average which is stored in this structure.
