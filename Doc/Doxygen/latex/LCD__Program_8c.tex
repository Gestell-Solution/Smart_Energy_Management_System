{\footnotesize\ttfamily Lines\+Of\+Display = \mbox{\hyperlink{LCD__Config_8h_aa50d9ab86403641ceecfad89227d088e}{Rows\+\_\+\+Addresses\+\_\+\+Array}}\hspace{0.3cm}{\ttfamily [static]}}



Holds the starting DDRAM addresses for each LCD row. 

This static array is initialized using the predefined macro Rows\+\_\+\+Addresses\+\_\+\+Array in the configuration file, which contains the start addresses for Row 1 to Row 4. It is used to calculate the cursor position on the LCD when setting the DDRAM address.
