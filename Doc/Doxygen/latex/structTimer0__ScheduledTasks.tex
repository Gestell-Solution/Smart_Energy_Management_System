\doxysubsection{Detailed Description}
Represents a scheduled task managed by Timer0. 

This structure holds the necessary information for a non-\/blocking delay task, including its callback function, remaining time in ticks, and active status. It is packed with 1-\/byte alignment to optimize memory usage in embedded systems. \begin{DoxyNote}{Note}
Used internally by the Timer0 scheduler to manage multiple concurrent tasks. 
\end{DoxyNote}
