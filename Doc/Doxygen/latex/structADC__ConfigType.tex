\doxysubsection{Detailed Description}
This structure holds the configuration parameters for the ADC module. 

This structure is used to initialize the ADC with specific settings such as prescaler, voltage reference, and channel selection. \begin{DoxyNote}{Note}
This structure is defined in the private header file and should not be modified directly by users.
