\doxysubsection{Detailed Description}
Implementation of the Communication Manager Module. 

This module handles the reception, decoding, and transmission of data frames over the communication interface (UART/\+Bluetooth). It implements a custom framing protocol to ensure data integrity and synchronization.

{\bfseries{Frame Structure\+:}} {\ttfamily \mbox{[}HEADER\mbox{]} \mbox{[}LENGTH\mbox{]} \mbox{[}COMMAND\mbox{]} \mbox{[}PAYLOAD...\mbox{]}}
\begin{DoxyItemize}
\item {\bfseries{HEADER}}\+: Start of Frame byte (0x\+AA).
\item {\bfseries{LENGTH}}\+: Total length of the frame payload (Command + Data).
\item {\bfseries{COMMAND}}\+: ID of the command or response type.
\item {\bfseries{PAYLOAD}}\+: Variable length data bytes.
\end{DoxyItemize}
