\doxysubsection{Detailed Description}
Implementation of the Energy Logger Module. 

This module manages the storage of electrical measurements (Voltage, Current, Power, Energy). It utilizes a two-\/stage storage mechanism\+:
\begin{DoxyEnumerate}
\item {\bfseries{RAM Circular Buffer}}\+: Temporary storage for high-\/frequency samples.
\item {\bfseries{EEPROM Storage}}\+: Persistent storage where RAM data is flushed periodically.
\end{DoxyEnumerate}

The logger handles buffer overflows by overwriting the oldest data in RAM, ensuring the most recent history is always preserved before committing to slower EEPROM. \begin{DoxyVersion}{Version}
