\doxysubsection{Detailed Description}
Implementation of the Analog-\/to-\/\+Digital Converter (ADC) Driver. 

This module configures the ATmega32 ADC peripheral. It supports\+:
\begin{DoxyItemize}
\item {\bfseries{Synchronous Mode}}\+: Blocking read ({\ttfamily m\+ADC\+\_\+\+Read}).
\item {\bfseries{Asynchronous Mode}}\+: Interrupt-\/driven round-\/robin sampling ({\ttfamily m\+ADC\+\_\+\+Start\+Group}).
\item {\bfseries{Configuration}}\+: configurable Reference voltage, Prescaler, and Trigger sources via {\ttfamily \doxylink{ADC__Config_8h}{ADC\+\_\+\+Config.\+h}}. \begin{DoxyVersion}{Version}
2.\+0
