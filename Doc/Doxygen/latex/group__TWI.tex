{\footnotesize\ttfamily m\+TWI\+\_\+\+Init (\begin{DoxyParamCaption}\item[{void}]{ }\end{DoxyParamCaption})}



Initializes the TWI (I2C) peripheral as Master and/or Slave. 

This function performs the following tasks\+:
\begin{DoxyEnumerate}
\item Sets the TWI bit rate according to the configuration macro {\ttfamily TWI\+\_\+\+Bit\+\_\+\+Rate}.
\item Resets all internal buffers (Master Tx/\+Rx, Slave Tx/\+Rx) to initial state.
\item Sets the TWI peripheral control register (TWCR) to\+:
\begin{DoxyItemize}
\item Enable TWI operation.
\item Enable TWI interrupt (TWIE).
\item Enable ACK (TWEA) for Slave reception.
\end{DoxyItemize}
\item Sets the initial driver state to IDLE.
\item Prepares the device to operate as Master and/or Slave according to configuration.
\end{DoxyEnumerate}

\begin{DoxyNote}{Note}
This function should be called once at system startup before any TWI operation. The actual data transmission/reception is handled asynchronously via ISR.
\end{DoxyNote}
