\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class Napi\+::\+Class\+Property\+Descriptor$<$ T $>$}
Property descriptor for use with {\ttfamily \doxylink{classNapi_1_1ObjectWrap_a0951856129efcd16c5db43efd7eb5528}{Object\+Wrap\+::\+Define\+Class()}}.

This is different from the standalone {\ttfamily \doxylink{classNapi_1_1PropertyDescriptor}{Property\+Descriptor}} because it is specific to each {\ttfamily \doxylink{classNapi_1_1ObjectWrap}{Object\+Wrap}\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} subclass. This prevents using descriptors from a different class when defining a new class (preventing the callbacks from having incorrect {\ttfamily this} pointers).
