\hypertarget{md_Readme_autotoc_md3482}{}\doxysection{\texorpdfstring{🧭 System Workflow}{🧭 System Workflow}}\label{md_Readme_autotoc_md3482}

\begin{DoxyEnumerate}
\item MCU continuously reads analog signals from ACS712 and Voltage Divider.
\item Calculate Irms, Vrms, Power (P = V × I), and cumulative Energy (k\+Wh).
\item Display values on LCD in real-\/time.
\item If power exceeds Threshold\+:
\begin{DoxyItemize}
\item Activate Buzzer + LED.
\item Disconnect load via Relay.
\end{DoxyItemize}
\item User can reset system or change display modes via buttons.
\item Data can be monitored via Bluetooth (mobile app) or Wi-\/\+Fi (cloud).
\end{DoxyEnumerate}
